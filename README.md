## What I Do

My work spans four connected areas:

- **IT & Infrastructure** — enterprise support, networks, MikroTik, VPNs, Windows, Linux and operational troubleshooting.
- **AI Engineering** — AI agents, LLM integrations, memory systems, automation and AI-assisted developer tooling.
- **Software & Web** — TypeScript, Python, Next.js, React, APIs, Supabase, FastAPI and production-oriented web applications.
- **Automation & DevOps** — GitHub Actions, CI/CD, Docker, Vercel and tooling that reduces manual operational work.

I am less interested in collecting technologies and more interested in using the right technology to solve the actual problem.
